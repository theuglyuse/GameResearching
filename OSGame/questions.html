OS Quest — Post-Play Assessment

Ten questions on applying Operating Systems concepts. Choose the single best answer for each.

1. Three processes arrive at time 0 with CPU bursts P1 = 8 ms, P2 = 2 ms, and P3 = 4 ms. Under non-preemptive Shortest-Job-First scheduling, what is P1's waiting time?

  1. A. 0 ms
  2. B. 6 ms
  3. C. 8 ms
  4. D. 14 ms

2. P1 (burst 6) and P2 (burst 3) both arrive at time 0, with P1 placed in the ready queue first. Using Round Robin with a time quantum of 4, which process completes first?

  1. A. P1
  2. B. P2
  3. C. They finish at the same time
  4. D. Cannot be determined

3. Thread 1 runs lock(A); lock(B); while Thread 2 runs lock(B); lock(A);. Which statement best describes the outcome?

  1. A. It always deadlocks
  2. B. It can deadlock, depending on the timing/interleaving of the two threads
  3. C. It can never deadlock because locks are reentrant
  4. D. It deadlocks only on a single-core CPU

4. With 3 page frames (all initially empty) and the reference string 7, 0, 1, 2, 0, 3, 0, 4 using LRU replacement, how many page faults occur?

  1. A. 5
  2. B. 6
  3. C. 7
  4. D. 8

5. A team measures page faults for a program and finds that increasing the number of frames from 3 to 4 caused more page faults. Which page-replacement policy are they most likely using?

  1. A. FIFO
  2. B. LRU
  3. C. Optimal (OPT)
  4. D. Any of them—frame count doesn't matter

6. Two threads each execute counter += 1 one thousand times on a shared counter (starting at 0) with no synchronization. Which final value is impossible?

  1. A. 1000
  2. B. 1500
  3. C. 2000
  4. D. 3000

7. A producer thread is written as wait(mutex); wait(empty); /* add item */ signal(full); signal(mutex); where empty counts free buffer slots and mutex guards the buffer. What is the danger?

  1. A. Nothing—this ordering is correct
  2. B. It can deadlock: the producer holds mutex while blocking on empty, so no consumer can ever free a slot
  3. C. It doubles throughput
  4. D. It causes a page fault on every insert

8. Thread A calls lock(M) and enters a critical section; before A finishes, Thread B calls unlock(M) on the same mutex. What is the problem?

  1. A. Nothing—it safely hands the lock to B
  2. B. It violates mutex ownership—only the thread that locked M should unlock it, so this is a bug with undefined behavior
  3. C. It improves fairness between threads
  4. D. It guarantees deadlock is prevented

9. The disk head is at cylinder 50. Pending requests are: 16, 24, 43, 82, 140, 170, 190. Using Shortest-Seek-Time-First (SSTF), which two requests are serviced first, in order?

  1. A. 16, then 24
  2. B. 43, then 24
  3. C. 82, then 140
  4. D. 43, then 82

10. Consider the following C code:

fork();
fork();
printf("hi\n");

Assuming both fork() calls succeed, how many times is hi printed?

  1. A. 1
  2. B. 2
  3. C. 4
  4. D. 8
